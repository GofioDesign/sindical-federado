# Seguridad y privacidad

Este repositorio es público. Nunca debe contener listados de afiliación, correos, teléfonos, respuestas individuales, consultas laborales, datos de salud, credenciales, tokens, cookies ni exportaciones sin depurar.

- Los secretos van en GitHub Actions Secrets o en el gestor del proveedor, nunca en JSON versionado.
- Los datos de Forms/Sheets permanecen privados y con acceso mínimo.
- Solo se publican resultados agregados con umbrales que eviten identificar personas o grupos pequeños.
- No se habilita autenticación en el MVP. Asociar identidad con afiliación sindical exige una evaluación jurídica y técnica específica.
- Los formularios generales deben advertir que no se envíen categorías especiales de datos.
- Las incidencias publicadas deben eliminar nombres, imágenes identificables, ubicaciones innecesariamente precisas y metadatos.

Para comunicar una vulnerabilidad, usa un canal privado de GOFIOdesign; no abras un issue público con detalles explotables.
